# Holy

Holy is a planned independent Linux distribution. This repository starts with
the C99 configuration parser and read-only local package inspector; it does not
contain a bootable distribution yet.

Run `make` to build the parser command and `make check` to test it. Read
`man/holy.conf.5` and `man/holypkg.8` for the implemented interface. The
full distribution specification still requires packaging, installation,
images, and runtime acceptance tests.

The similarly named `owenewans/holypkg` repository is a separate project.
